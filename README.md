# 뱅드림 라이브 일정

BanG Dream! 공식 사이트(<https://bang-dream.com/events/>)의 라이브·이벤트 목록을 매일 한 번 모아
보여 주는 개인 팬 일정표입니다. 공식 사이트가 아니며, 티켓 구매 전에는 반드시 공식 페이지를 확인하세요.

- `scraper/scrape.py`: 공식 목록과 상세 페이지에서 날짜·장소·출연·표 가격을 읽어 `data.json`을 만듭니다.
  하루 한 번, 요청 사이 1.5초 간격, 상세 페이지는 새 공연·가격 없는 공연은 매일, 그 외는 사흘에 한 번 다시 받습니다(티켓 추첨 단계 갱신).
- `.github/workflows/update.yml`: 매일 06:17(JST) 실행, 바뀐 내용이 있을 때만 커밋합니다.
- `index.html`, `app.js`, `style.css`: GitHub Pages에서 `data.json`을 읽어 그립니다.

공식 이미지나 공지 본문은 가져오지 않고, 각 공연은 공식 상세 페이지로 링크합니다.
